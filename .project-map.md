# Project Map

> Navigation cache. Source files are authoritative.

## Project

Java 21 Spring Boot backend for language content, vocabulary study, and German-learning practice flows.

## Areas

- `src/main/java/com/myriadcode/languagelearner/language_learning_system/` — application orchestration, practice domains, REST controllers, MCP generation, and persistence
- `src/main/java/com/myriadcode/languagelearner/language_content/` — generated language-content contracts and services
- `PromptsGenerator.java` — shared reading, writing, and CEFR-aware Word Practice generation prompt construction
- `src/main/java/com/myriadcode/languagelearner/flashcards_study/` — flashcard review state, scheduling, and review logs
- `src/main/resources/db/migration/` — Flyway database schema; latest migration: `V29__word_practice.sql`
- `src/test/` — unit, architecture, and Spring/Testcontainers integration tests

## Ownership

content generation/
- `ContentGenerationJobType.java` — generation job type registry
- `WritingPracticeMcpTools.java` — two-phase writing-practice MCP fetch/store boundary
- `WordPracticeMcpTools.java` — two-phase Word Practice prompt fetch and atomic store boundary

vocabulary/
- `VocabularyRepo.java` — vocabulary persistence contract and user-owned lookup
- `VocabularyFlashcardReviewsAdapter.java` — flashcard review data exposed to learning-system selection
- `RecentExerciseVocabularyUsageService.java` — recent reading/writing contextual-use counts

word practice/
- `WordPractice.java` — unresolved contextual exercise and answer matching
- `WordPracticeSelectionPolicy.java` — quota, ranking-window, fallback, and random selection of ten vocabulary words
- `WordPracticeBatchValidator.java` — authoritative-word, context-count, uniqueness, and mixed-direction generation rules
- `WordPracticeCapacityPolicy.java` — fifteen-active-vocabulary capacity boundary
- `WordPracticeGenerationRequestService.java` — capacity-gated generation job creation
- `WordPracticeGenerationService.java` — candidate selection, profile-level prompt preparation, and atomic generated-batch orchestration without persisted generation state
- `WordPracticeAnswerService.java` — correct-answer deletion boundary; wrong answers retain the exercise
- `WordPracticeController.java` — REST queue, answer-submission, and generation-request entry points
- `infra/jpa/word_practice/` — active-practice persistence, candidate queries, and consumed weak-review events

## Routes

- MCP-generated practice flow -> `WritingPracticeGenerationRequestService.java` -> `WritingPracticeMcpTools.java` -> `WritingPracticeService.java`
- Word Practice generation -> `WordPracticeController.java` -> `WordPracticeGenerationRequestService.java` -> `WordPracticeMcpTools.java` -> `WordPracticeGenerationService.prepareGenerationPrompt/store` -> `WordPracticeRepo.java`
- Word Practice exercise loop -> `WordPracticeController.java` -> `WordPracticeQueryService.java` / `WordPracticeAnswerService.java` -> `WordPracticeRepo.java`
- vocabulary ownership and metadata -> `VocabularyRepo.java` -> `VocabularyJpaRepoImpl.java`
- flashcard weakness/review history -> `VocabularyFlashcardReviewsAdapter.java` -> `FlashCardReview.java` -> `ReviewLog.java`

## Invariants

- Content-generation jobs identify pending work by user and generation type; MCP storage deletes the job only after successful persistence.
- Vocabulary IDs remain authoritative across generated-content flows; user ownership is checked during lookup.
- Flashcard scheduling belongs to `flashcards_study/`; contextual practice may read review state without changing FSRS scheduling.
- Word Practice capacity counts distinct active vocabulary IDs; each selected vocabulary owns three to five unresolved exercises.
- Every Word Practice generation batch contains both German-to-English and English-to-German exercises; no direction history is retained.
- Word Practice stores no generation snapshots, counters, attempts, or historical statistics.
