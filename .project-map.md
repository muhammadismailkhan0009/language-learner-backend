# Project Map

> Navigation cache. Source files are authoritative.

## Project

Java 21 Spring Boot backend for language content, vocabulary study, and German-learning practice flows.

## Areas

- `src/main/java/com/myriadcode/languagelearner/language_learning_system/` — application orchestration, practice domains, REST controllers, MCP generation, and persistence
- `src/main/java/com/myriadcode/languagelearner/language_content/` — generated language-content contracts and services
- `src/main/java/com/myriadcode/languagelearner/flashcards_study/` — flashcard review state, scheduling, and review logs
- `src/main/resources/db/migration/` — Flyway database schema; latest migration: `V28__writing_practice_free_writing.sql`
- `src/test/` — unit, architecture, and Spring/Testcontainers integration tests

## Ownership

content generation/
- `ContentGenerationJobType.java` — generation job type registry
- `WritingPracticeMcpTools.java` — two-phase writing-practice MCP fetch/store boundary

vocabulary/
- `VocabularyRepo.java` — vocabulary persistence contract and user-owned lookup
- `VocabularyFlashcardReviewsAdapter.java` — flashcard review data exposed to learning-system selection
- `RecentExerciseVocabularyUsageService.java` — recent reading/writing contextual-use counts

## Routes

- MCP-generated practice flow -> `WritingPracticeGenerationRequestService.java` -> `WritingPracticeMcpTools.java` -> `WritingPracticeService.java`
- vocabulary ownership and metadata -> `VocabularyRepo.java` -> `VocabularyJpaRepoImpl.java`
- flashcard weakness/review history -> `VocabularyFlashcardReviewsAdapter.java` -> `FlashCardReview.java` -> `ReviewLog.java`

## Invariants

- Content-generation jobs identify pending work by user and generation type; MCP storage deletes the job only after successful persistence.
- Vocabulary IDs remain authoritative across generated-content flows; user ownership is checked during lookup.
- Flashcard scheduling belongs to `flashcards_study/`; contextual practice may read review state without changing FSRS scheduling.
